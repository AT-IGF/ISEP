ISEP documentation
==================

**ISEP (Integrated Solution for Environmental Pollen detection)** provides
utilities for handling Rapid-E particle measurements, visualizing data,
building models, running predictions, and mapping results.

This documentation describes how ISEP modules can be used from Python
scripts or Jupyter notebooks in addition to the graphical interface.

.. important::

   The :doc:`api_reference` is generated by the standard Sphinx
   ``apidoc`` and ``autodoc`` extensions. Undocumented functions may appear
   by name and signature only. A listed function is not necessarily a stable
   standalone API. Building the reference imports ISEP Python modules.
