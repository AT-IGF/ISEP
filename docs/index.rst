ISEP Documentation
==================

**ISEP (Integrated Solution for Environmental Pollen detection)**
provides tools for processing Rapid-E particle measurements, visualizing data,training machine learning models, generating predictions, and mapping results.

This documentation describes ISEP's functionality and Python modules. Users can interact with ISEP through its graphical user interface (GUI) or develop custom analysis workflows using Python scripts or Jupyter notebooks.
